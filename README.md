## 📂 Projects

### 01 — Color Scheme Changer

A simple color scheme changer built with JavaScript.

**Concepts:** DOM manipulation, events, CSS styling.

### 02 — BMI Calculator

A BMI calculator that takes height and weight as input and calculates the user's BMI.

**Concepts:** DOM manipulation, form handling, calculations, conditional logic.

### 03 — Digital Clock

A responsive digital clock displaying the current date and time with a **12-hour / 24-hour slider**.

**Concepts:** Date object, `Intl.DateTimeFormat`, DOM manipulation, event listeners, responsive CSS.
